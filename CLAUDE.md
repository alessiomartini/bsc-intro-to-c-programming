# Claude Code instructions

## Project

Archive of introductory C programming exercises and lecture material.

## Workflow

- Read `README.md` and the relevant exercise before editing.
- Compile and run the smallest affected C file with the existing compiler
  conventions; check warnings and representative output.
- Preserve historical examples and educational intent.
- Do not change input/output formats, algorithms, or filenames without approval.
- Keep binaries and temporary compiler files out of git; inspect the diff before committing.
